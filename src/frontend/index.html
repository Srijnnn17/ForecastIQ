    Forecast & Backtest Architecture

    ForecastIQ runs three statistical models in parallel and evaluates them via walk-forward backtesting to surface the best-performing approach for your data.

    Input
    📂 Dataset (CSV) Date + value column
    ↓ POST /api/forecast
    Backend
    🐍 Flask Route forecast.py
    🔢 Preprocessor Resample · Impute · Scale
    ↓ Parallel model fitting
    Models
    📈 ETS Error · Trend · Season (statsmodels)
    📉 ARIMA(1,1,1) Auto-differencing (statsmodels)
    〰️ Moving Avg Rolling window baseline
    ↓ Walk-forward validation
    Evaluation
    🎯 MAPE Mean Abs % Error
    📏 RMSE Root Mean Sq Error
    ✅ Hit Rate Direction accuracy
    ↓ Best model selected · AI Analysis generated
    Output
    🏆 Leaderboard Ranked model scores
    🔮 Forecast Chart Confidence bands · horizon
    ✨ Gemini Narrative Plain-English AI Analysis
    statsmodels — ETS & ARIMA fitting
    Gemini 2.5 Flash — AI Analysis narrative
    Walk-forward split — honest out-of-sample evaluation
